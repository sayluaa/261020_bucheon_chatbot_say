# 🎯 자기개발 메이트

취업을 준비하는 사람을 위한 터미널 챗봇입니다. 공부, 일상 기록, 취업 코칭을 한 곳에서 하고,
내 목표 직무와 공부 중인 과목에 맞춰 답해줍니다. (groq API)

## 기능

| 모드 | 하는 일 |
|------|---------|
| 1. 공부 메이트 | 퀴즈 출제·채점, 코딩 질문에 힌트 먼저 제공 |
| 2. 일상 기록 | "점심 9천원", "파이썬 2시간 공부"처럼 말하면 `data/log.json`에 자동 저장 |
| 3. 취업 코치 | 직무 설명, 자소서 첨삭, 모의 면접(질문 → 장점·보완점·점수). 붙여넣은 채용 공고 저장, 직무별 자격증 추천, 면접 일정 기록 |

- 처음 실행하면 목표 직무와 공부 중인 과목을 물어보고 `data/profile.json`에 저장합니다. 이후 모든 모드에 반영됩니다.
- groq 호출이 실패하면(한도 소진 등) gemini로 자동 전환합니다. (`GEMINI_API_KEY` 필요)

## 설치

```bash
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## API 키 설정

`.env.example`을 복사해서 `.env`를 만들고 키를 넣습니다. `.env`는 `.gitignore`에 포함되어 깃에 올라가지 않습니다.

```
GROQ_API_KEY=발급받은_groq_키
GEMINI_API_KEY=발급받은_gemini_키   # 선택: groq 한도 소진 시 폴백
```

## 실행

**터미널 버전**

```bash
python chatbot.py
```

모드 번호를 고르고 대화합니다. 종료는 `exit`.

**웹 버전** (같은 챗봇 로직을 화면으로 감싼 버전)

```bash
streamlit run web.py
```

브라우저에서 `http://localhost:8501`이 열립니다. 모드별 테마 색과 기록 탭을 제공합니다.

| 모드 | 기록 탭 |
|------|---------|
| 공부 메이트 | 📊 공부 기록: 이번 주 공부 시간, 일별·과목별 차트 |
| 일상 기록 | 📊 이번 주 기록: 공부 시간, 지출, 일정 |
| 취업 코치 | 📊 취업 준비: 저장한 공고(마감 임박순, D-day), 일정, 추천 자격증, 사람인·잡코리아 검색 링크 |

## 파일 구조

```
chatbot.py        챗봇 본체 (대화 루프, 모드, 기록 저장, gemini 폴백)
web.py            웹 화면 (chatbot.py의 함수를 가져다 사용)
data/             profile.json, log.json (자동 생성, 깃 제외)
requirements.txt  필요 라이브러리
```

## 한계

- 모델은 실시간 인터넷 검색을 하지 않습니다. 채용 공고는 직접 붙여넣은 내용만 저장하고, 최신 가격 같은 정보는 알 수 없습니다.
- 자격증 추천은 AI의 일반 지식이라 종료된 자격증이 섞이거나 시험 일정·응시료가 틀릴 수 있습니다. 큐넷(q-net.or.kr) 등 공식 사이트에서 확인하세요.
- 기록은 AI 답변의 `RECORD:` 줄에서 추출하므로, 가끔 형식이 틀리면 저장되지 않을 수 있습니다.
